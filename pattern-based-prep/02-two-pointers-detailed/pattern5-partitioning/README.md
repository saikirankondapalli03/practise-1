# Three Pointers - Partitioning

## 🎯 Pattern Description
Partition array into 3 sections using Dutch Flag algorithm. Use for 'sort colors', '3-way partition'.

## 📝 Template Approach
**Strategy:** left boundary, right boundary, current pointer processes unknown section
**Time Complexity:** O(n)
**Space Complexity:** O(1)

## 📚 Problems (1)

### DutchFlag.java
**Difficulty:** Medium
**Description:** Sort array of 0s, 1s, and 2s (Dutch Flag problem)
**Key Concept:** Three pointers: left (0s), right (2s), current (processing)
