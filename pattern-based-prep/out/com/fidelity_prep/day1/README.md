# Day 1: Core Patterns - Two Pointers & Sliding Window

## 🎯 Today's Goal
Rebuild muscle memory + learn to write logical steps BEFORE coding

## ⏰ Schedule (8 hours)
- **Morning (3 hours)**: Problems 1-3
- **Afternoon (3 hours)**: Problems 4-6
- **Evening (2 hours)**: Review + complexity analysis

## 📝 How to Approach Each Problem

### Step 1: Pattern Recognition (2 min)
- Look at the problem
- Identify which pattern applies
- Say: "This is [pattern] because..."

### Step 2: Logical Breakdown (5-10 min) - **MOST IMPORTANT**
Write in plain English:
- "I need to..."
- "When I see X, I should..."
- "The tricky part is..."
- Draw examples on paper

### Step 3: Code (15-20 min)
- Follow your logical steps
- Don't skip ahead
- Test with examples as you code

### Step 4: Review (5 min)
- Compare with solution
- See where your logic differed
- Refactor if needed
