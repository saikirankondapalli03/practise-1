## 📝 How to Approach Each Problem

### For Tree Problems:
1. **Draw the tree** - Visualize examples first
2. **Write recursive logic in words** - "For each node, I need to..."
3. **Identify base case** - "When do I stop recursing?"
4. **Code step-by-step** - Follow your logic

### For Heap Problems:
1. **Identify what to optimize** - Min or max?
2. **Choose heap type** - Min-heap or max-heap?
3. **Think about when to add/remove** - What triggers heap operations?
4. **Code with heap operations** - poll(), offer(), peek()
