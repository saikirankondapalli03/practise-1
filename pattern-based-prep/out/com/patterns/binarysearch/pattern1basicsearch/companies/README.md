# Company Interview Questions - Basic Search

## 🏢 Most Asked Questions for SDE-2 Positions

### Amazon
- **Binary Search** - Classic binary search implementation
- **Search in Infinite Array** - Search without knowing array bounds
- **First Bad Version** - Find first occurrence using binary search
- **Guess Number Higher or Lower** - Interactive binary search

### Google
- **Binary Search** - Fundamental algorithm implementation
- **Search Insert Position** - Find insertion point in sorted array
- **Peak Index in Mountain Array** - Find peak using binary search
- **Valid Perfect Square** - Check if number is perfect square

### Microsoft
- **Binary Search in Rotated Array** - Handle rotation in sorted data
- **Find Minimum in Rotated Sorted Array** - Locate minimum element
- **Search for Range** - Find first and last occurrence
- **Sqrt(x)** - Integer square root using binary search

### Meta (Facebook)
- **Binary Search** - Core algorithm for data processing
- **Search in 2D Matrix** - Extended binary search concepts
- **Find Peak Element** - Local maximum finding
- **Single Element in Sorted Array** - Find unique element

### Apple
- **Binary Search** - System-level search algorithms
- **Search Suggestions System** - Autocomplete with binary search
- **Capacity to Ship Packages** - Optimization using binary search
- **Koko Eating Bananas** - Rate optimization problems

### Netflix
- **Content Search Algorithms** - Efficient content discovery
- **Recommendation Ranking** - Binary search in recommendation systems
- **Load Balancing** - Server selection using binary search
- **Cache Optimization** - Binary search for cache management

## 💡 Interview Tips
- Master iterative and recursive implementations
- Handle edge cases (empty array, single element)
- Explain why binary search works (sorted property)
- Discuss when to use vs linear search
