# Company Interview Questions - Fixed Size Sliding Window

## 🏢 Most Asked Questions for SDE-2 Positions

### Amazon
- **Maximum Sum Subarray of Size K** - Find maximum sum of any subarray of size k
- **Average of Subarrays of Size K** - Calculate average of all subarrays of size k
- **Maximum Cards Sum** - Pick k cards from either end to maximize sum
- **Sliding Window Maximum** - Find maximum in each window of size k

### Google
- **Sliding Window Maximum** - Maximum element in each sliding window
- **Maximum Sum of K Consecutive Elements** - Optimize picking k consecutive elements
- **Fixed Window Statistics** - Calculate various statistics for fixed-size windows

### Microsoft
- **Maximum Sum Subarray of Size K** - Classic sliding window optimization
- **K-Size Subarray Averages** - Efficient average calculation
- **Window-based Data Processing** - Real-time data stream processing

### Meta (Facebook)
- **Maximum Cards from Deck** - Strategic card selection problem
- **Fixed Window Analytics** - Social media engagement metrics
- **K-Length Substring Problems** - String processing with fixed windows

### Apple
- **Sliding Window Maximum** - UI component optimization
- **Fixed-Size Buffer Processing** - System-level data processing
- **K-Element Window Operations** - Hardware-software interface problems

### Netflix
- **Content Recommendation Windows** - Fixed-size recommendation algorithms
- **Streaming Buffer Analysis** - Video streaming optimization
- **User Engagement Metrics** - Fixed-time window analytics

## 💡 Interview Tips
- Master the template before interviews
- Practice explaining the sliding technique
- Discuss time/space complexity improvements
- Show optimization from brute force to sliding window
