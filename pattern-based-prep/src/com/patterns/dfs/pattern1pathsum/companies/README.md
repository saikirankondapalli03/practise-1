# Company Interview Questions - Path Sum

## 🏢 Most Asked Questions for SDE-2 Positions

### Amazon
- **Path Sum** - Check if root-to-leaf path exists with target sum
- **Path Sum II** - Find all root-to-leaf paths with target sum
- **Binary Tree Maximum Path Sum** - Find maximum sum path in tree
- **Sum Root to Leaf Numbers** - Sum all root-to-leaf path numbers

### Google
- **Path Sum III** - Count paths with target sum (not necessarily root-to-leaf)
- **Binary Tree Maximum Path Sum** - Global maximum path sum
- **Diameter of Binary Tree** - Longest path between any two nodes
- **Lowest Common Ancestor** - Find LCA using path information

### Microsoft
- **Path Sum** - Basic tree traversal with sum tracking
- **Maximum Path Sum in Binary Tree** - Dynamic programming on trees
- **Root to Leaf Path Sum** - Validate path sums
- **Tree Path Sum Equal to Target** - Multiple path validation

### Meta (Facebook)
- **Binary Tree Paths** - Generate all root-to-leaf paths
- **Path Sum II** - Social network connection paths
- **Maximum Path Sum** - Optimization in tree structures
- **Sum of Left Leaves** - Selective path sum calculation

### Apple
- **Path Sum Variants** - File system path calculations
- **Binary Tree Maximum Path Sum** - Resource optimization trees
- **Root to Leaf Paths** - Configuration path validation
- **Tree Traversal with Conditions** - Conditional path processing

### Netflix
- **Content Recommendation Paths** - User journey path analysis
- **Decision Tree Path Sums** - ML model path calculations
- **User Engagement Paths** - Path-based analytics
- **A/B Test Path Analysis** - Experiment path tracking

## 💡 Interview Tips
- Master recursive tree traversal patterns
- Understand when to pass vs return values
- Practice handling negative numbers in paths
- Explain difference between any path vs root-to-leaf path
