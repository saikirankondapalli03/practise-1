# Hybrid - Window with Sorting

## 🎯 Pattern Description
Combines sliding window with sorting concepts. Use for problems requiring both techniques.

## 📝 Template Approach
**Strategy:** Find unsorted window boundaries using two pointers
**Time Complexity:** O(n)
**Space Complexity:** O(1)

## 📚 Problems (1)

### ShortestWindowSort.java
**Difficulty:** Medium
**Description:** Find shortest window that needs to be sorted to make array sorted
**Key Concept:** Find leftmost and rightmost out-of-order elements
