# Opposite Direction - Quadruplets

## 🎯 Pattern Description
Extension of triplet approach for four elements. Use for 'four sum', 'quadruplet' problems.

## 📝 Template Approach
**Strategy:** Nested loops for first two elements, two pointers for last two
**Time Complexity:** O(n³)
**Space Complexity:** O(1) excluding result

## 📚 Problems (1)

### QuadrupleSumToTarget.java
**Difficulty:** Medium
**Description:** Find all unique quadruplets that sum to target
**Key Concept:** Fix two elements with nested loops, two pointers for remaining two
