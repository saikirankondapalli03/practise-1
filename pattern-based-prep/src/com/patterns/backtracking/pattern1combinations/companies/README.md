# Company Interview Questions - Combinations

## 🏢 Most Asked Questions for SDE-2 Positions

### Amazon
- **Generate Parentheses** - Generate all valid parentheses combinations
- **Letter Combinations of Phone Number** - Generate all letter combinations
- **Combination Sum** - Find all combinations that sum to target
- **Word Break II** - Return all possible word break combinations

### Google
- **Generate Parentheses** - Classic backtracking problem
- **Palindrome Partitioning** - Find all palindrome partitions
- **Restore IP Addresses** - Generate all valid IP address combinations
- **Binary Watch** - Generate all possible times

### Microsoft
- **Combination Sum II** - Combinations with duplicate handling
- **Factor Combinations** - Find all factor combinations of number
- **Letter Case Permutation** - Generate all case combinations
- **Subsets II** - Generate subsets with duplicates

### Meta (Facebook)
- **Generate Parentheses** - UI component generation
- **Combination Sum** - Ad targeting combinations
- **Word Ladder II** - Find all shortest transformation paths
- **Remove Invalid Parentheses** - String validation combinations

### Apple
- **Generate Parentheses** - Code generation problems
- **Combination Sum** - Hardware configuration combinations
- **Letter Combinations** - Input method combinations
- **Valid Parentheses Strings** - Syntax validation

### Netflix
- **Content Combination Algorithms** - Recommendation combinations
- **User Preference Combinations** - Personalization algorithms
- **A/B Testing Combinations** - Experiment design combinations

## 💡 Interview Tips
- Master the choose-explore-unchoose pattern
- Practice pruning invalid branches early
- Explain time complexity as O(2^n) or O(k^n)
- Show how to avoid duplicate combinations
