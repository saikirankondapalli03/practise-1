# Company Interview Questions - Permutations

## 🏢 Most Asked Questions for SDE-2 Positions

### Amazon
- **Permutations** - Generate all permutations of array
- **Permutations II** - Generate permutations with duplicates

### Google
- **Next Permutation** - Find lexicographically next permutation
- **Permutation Sequence** - Find kth permutation sequence

### Microsoft
- **String Permutations** - Generate all permutations of string
- **Permutation in String** - Check if permutation exists

### Meta (Facebook)
- **Letter Case Permutation** - Generate all case permutations
- **Permutations** - All possible arrangements

### Apple
- **Permutation Algorithms** - System-level permutation generation
- **Configuration Permutations** - Hardware setup variations

### Netflix
- **Content Arrangement** - Recommendation permutations
- **A/B Test Permutations** - Experiment variations

## 💡 Interview Tips
- Master swap-based backtracking
- Handle duplicate elements correctly
- Explain time complexity as O(n!)
- Show iterative vs recursive approaches
