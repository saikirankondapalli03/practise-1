## 📝 Mock Interview Format

### For Each Problem (45 minutes):
1. **Understand (5 min)**
   - Read problem carefully
   - Ask clarifying questions (to yourself)
   - Identify constraints

2. **Plan (10 min)**
   - Pattern recognition
   - Write logical approach
   - Identify edge cases
   - Estimate complexity

3. **Code (25 min)**
   - Implement solution
   - Test with examples
   - Handle edge cases

4. **Review (5 min)**
   - Check solution
   - Identify improvements
   - Note what went well/wrong
