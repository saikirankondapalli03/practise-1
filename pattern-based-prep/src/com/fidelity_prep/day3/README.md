# Day 3: Backtracking & Binary Search

## 🎯 Today's Goal
Master decision-making logic + search space reduction

## ⏰ Schedule (8 hours)
- **Morning (3 hours)**: Problems 1-3 (Backtracking)
- **Afternoon (3 hours)**: Problems 4-6 (Binary Search)
- **Evening (2 hours)**: Review + complexity analysis

## 📝 How to Approach Each Problem

### For Backtracking Problems:
1. **Identify choices** - What decisions do I make at each step?
2. **Write decision tree** - Draw choices and outcomes
3. **Identify base case** - When do I stop and add to result?
4. **Code: Choose → Explore → Unchoose**

### For Binary Search Problems:
1. **Identify search space** - What am I searching for?
2. **Identify condition** - When to go left vs right?
3. **Handle boundaries** - When to include/exclude mid?
4. **Test with examples** - Verify logic with edge cases
