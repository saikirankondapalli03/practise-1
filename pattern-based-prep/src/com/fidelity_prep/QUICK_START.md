## 🎯 How to Use Each Problem File

Each problem file follows this structure:

1. **STEP 1: Pattern Recognition (2 min)**
   - Identify which pattern applies
   - Already filled in for you

2. **STEP 2: Logical Breakdown (5-10 min)** ⚠️ **MOST IMPORTANT**
   - **YOU WRITE THIS** - in plain English
   - "I need to..."
   - "When I see X, I should..."
   - "The tricky part is..."
   - Draw examples

3. **STEP 3: Code Implementation (15-20 min)**
   - Follow your logical steps
   - Code in the TODO section
   - Test with provided examples

4. **STEP 4: Solution (Check after)**
   - Compare with your solution
   - See where logic differed
   - Learn from differences

## ✅ Success Strategy

### The Key: Write Logic BEFORE Code

**❌ DON'T:**
- Jump straight to coding
- Copy patterns without understanding
- Skip the logical breakdown step

**✅ DO:**
- Write logical steps in plain English first
- Draw examples
- Think through edge cases
- Code following your logic
- Compare and learn

### Example of Good Logical Breakdown:

```
Problem: Two Sum

Logical Steps:
1. I need to find two numbers that add up to target
2. Since array is sorted, I can use two pointers
3. Start with left=0, right=length-1
4. If sum < target: move left (need bigger)
5. If sum > target: move right (need smaller)
6. If sum == target: found it!
```
